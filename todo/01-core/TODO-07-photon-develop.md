# TODO-07 -- Photon.Core Develop Engine: the Scene-Referred Pipeline for Imago's Camera Raw Filter and Lumen

> **Goal:** `src/Photon.Core/Develop/` holds the suite's one develop engine: a versioned `DevelopSettings` record and a float32 linear-light, scene-referred pipeline (white balance, exposure and tone, profiles as LUTs, curves, presence, color mixer and grading, calibration, negative inversion, sharpening and noise, grain and vignette, lens profiles and geometry), a resolution-independent local masking engine, spot healing and red eye, and presets, snapshots, and Camera Raw (`crs`) XMP exchange. Imago's Camera Raw filter and Develop studio (`D03 T15 §1`, `D03 T15 §2`, `D03 T15 §12`) are its first consumer and Lumen's develop module (`D04 T02 §2`) its planned second, which the integration that lands this file rewrites to consume §1 to §3 instead of building a pipeline inside Lumen's own assembly. The engine references no WPF, no Imago or Lumen type, and never opens a source file for writing; every stage is a pure function of its input tile and the settings, with a scalar reference beside its SIMD path, and settings are data that the consumers' histories undo.

> [!IMPORTANT]
> **Current state (verified 2026-09-26):** There is no `src/Photon.Core/` project yet, and so no `Develop/` folder; `D01 T02 §1` creates the project. Lumen has no source tree (`src/Lumen/` is absent), and its develop file was authored before this engine, planning its own stages inside `Photon.Lumen.Core`; the integration that lands this file rewrites `D04 T02 §2` to consume this one. Imago has no develop code at all: no source file under `src/Imago/src/` mentions `Develop`, and its adjustment enum in `src/Imago/src/Imago.Core/Layers/AdjustmentLayer.cs` names `Exposure` and `Vibrance` only as display-referred adjustment layers. No code anywhere in `src/` reads a lens database. `standards/lumen.md` already fixes the contract this engine meets: float32 linear light with one output transform at the end, and previews and exports of the same settings agreeing within a stated tolerance.

## 1. The Develop Pipeline Core: White Balance, Exposure, Tone, and Curves

This section fixes the settings record, the stage contract, the working space (linear ProPhoto primaries at D50, values unbounded until one output transform at the end), the input seam for RAW and layer sources, and the first stages, and proves them against darktable goldens and a preview budget. ## 2. Presence and Color: Texture, Clarity, Dehaze, Color Mixer, and Grading
