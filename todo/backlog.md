# Isotone -- Backlog

Ideas worth keeping that are not planned work. Nothing here is a section: an entry has no Implementation Order row, no phase, no checklist, and no owner, so no runner ever picks one up, `plan --check` never counts one, and nothing may defer work to one. The format spec, the admission test, and the budget are in [`README.md`](./README.md) under "The budget and the backlog". There is no cap: since 2026-09-27 the backlog holds as many entries as it needs (operator decision: "the cap is worrying me, because I'm worried features will be left behind."; [`budget.json`](./budget.json) records `backlog_cap: null`).

**Entry grammar.** One line per entry: the id in brackets, the title, then ` -- key: value` fields. Required: `source` (one key token: a legacy key, a finding ID, or the `-> SOURCE:` key the section would carry), `added` (YYYY-MM-DD), `why deferred`, and `promote when`. Optional: `app`, `summary`, and `needs` (full `DNN TNN §N` refs to live sections, or other backlog ids). Ids are `B-NNN`, taken in order and never reused. Optional and repeatable: ``merged: `<source-key>` `` for each entry folded into this one, and `reviewed:` for each release's backlog review. `validate` refuses a malformed line, a duplicate id or source, an entry whose source a live section already carries, a dead or short section ref, and an entry that left the file without a trace.

**Promotion** is `add-todo` on the entry (with its admission test and Origin line when a campaign promotes it on its own; nothing is capped): the promoting commit writes the real section (carrying this entry's source as its `-> SOURCE:` line) and deletes the entry. An entry leaves this file only by that promotion, by a merge that keeps its key as a merge marker on the surviving entry, or with the operator's words in a removal record under "Removed with operator approval" below. **Triage** is `groom-plan`: merge duplicates, ask the operator before removing anything, and promote what has come due; every release section runs the backlog review for its app before it stamps.
