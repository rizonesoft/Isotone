## 1. Smart Filters, Live Filter Layers, and Non-Destructive Layer Filters

Photoshop's smart filters, Affinity's live filter layers, and GIMP 3's layer filters are three shapes of one idea: a filter recorded as a description with its own mask and blending, re-rendered from the original pixels whenever anything upstream changes. This section builds one `FilterStack` that serves all three, one new layer kind for Affinity's live filter layers, a filter brush, and a render-graph node that caches each entry's output so re-editing stays interactive. Every warp, liquify, lens, and Camera Raw surface later hosts its live form here. The wavelet denoise brush (IP-1065) is this section's filter brush painting `D01 T06 §5`'s `WaveletDenoise` through a mask. Catalog: IP-0998 to IP-1012, IP-1065, IP-2368 (17 features: convert for smart filters, the smart filter stack, the filter mask, per-filter blending, copying filters between layers, live filter layers, the live filter mask, merge or delete a live filter, blend ranges on live filter layers, the filter brush, live-by-default application, smart filters on smart objects, live filter layer placement, GIMP 3 layer effects, filters on pass-through groups, the wavelet denoise brush, and smart brushing).
