## 3. The CMake Build, Presets, and the Test Harness

> **Started:** 2026-10-23T12:15:08Z

The build description is CMake with Ninja and committed presets that Visual Studio also opens (spec, "Build description"). C++23 comes from an explicit `/std:c++23preview`, because CMake turns `CXX_STANDARD 23` into `/std:c++latest` on MSVC, which the standard decision forbids.
