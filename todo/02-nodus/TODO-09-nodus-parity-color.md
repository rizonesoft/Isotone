# TODO-09 -- Nodus Parity: Color, Fills, Strokes, Brushes, Transparency, Styles, and Symbols

> **Goal:** Nodus paints like Illustrator 30.8 and CorelDRAW 2026: a color model that carries RGB, CMYK, HSB, Lab, grayscale, spot, global, and tint values through Photon.Core color management (`D01 T04 §1`); one Color panel and picker, eyedroppers, swatches, palettes, color styles and harmonies, and Recolor; linear, radial, conical, rectangular, freeform, and mesh gradients; pattern, texture, and procedural fills with a fill library; a full stroke model with arrowheads, dashes, alignment, and variable width; stacked appearances and reusable styles; art, pattern, scatter, calligraphic, bristle, and painterly brushes; every standard blend mode, opacity masks, and fountain transparency; and dynamic, 9-slice, nested, and library-linked symbols with the symbolism tools. Every paint attribute persists in SVG through the live-object contract (`D02 T07 §1`), every edit is one undoable command, and every palette, brush, style, and symbol library a user owns imports and exports. This file promotes backlog B-003 (`legacy-nodus-4.2-1.4`) into §3 and B-010 (`legacy-nodus-6`) into §16.

> [!IMPORTANT]
> **Current state (verified 2026-09-26):** Nodus's color is one 8-bit RGBA struct (`src/Nodus/Bezier.Core/Models/Color.cs`) with HSL, HSV, and hex helpers and no CMYK, Lab, or spot type. Five fill types exist under `src/Nodus/Bezier.Core/Models/Fills/` (solid, linear, radial, pattern, none), and `PatternFill` exists in the model but `src/Nodus/Bezier.Core/Services/SvgExporter.cs` never writes it. `Stroke` (`src/Nodus/Bezier.Core/Models/Stroke.cs`, 89 lines) holds width, opacity, cap, join, miter limit, and dash array only: no alignment, arrowheads, or width profile. A 12-member `BlendMode` enum sits on `VectorElement`, but neither the SVG writer nor `src/Nodus/Bezier.Desktop/Services/SkiaRenderer.cs` reads it, and Hue, Saturation, Color, and Luminosity are missing. The Properties panel's Fill row in `src/Nodus/Bezier.Desktop/Views/MainWindowView.xaml` is a static placeholder showing a literal hex, not a bound color. There is no eyedropper tool; `src/Nodus/Bezier.Core/Tools/` holds 10 files. `Symbol` and `SymbolInstance` exist with an `Overrides` dictionary (`src/Nodus/Bezier.Core/Models/Symbol.cs`), but the SVG writer never writes an instance. `src/Photon.Core/` does not exist yet, so no color-management engine exists anywhere in the tree.

- Every paint stores its authored color model (RGB, CMYK, HSB, HSL, Lab, gray), spot and registration colors, global swatch references with tints, and overprint flags, and round-trips through SVG exactly with an sRGB fallback any viewer renders.
- A Color panel, a color picker, recent colors, the color and attributes eyedroppers, swatches with global colors, a palette bar, a palette manager and editor, color styles with harmonies, the Color Guide, and Recolor Artwork all work from one swatch model.

- Linear, radial, conical, rectangular, freeform, stroke, and mesh gradients render and persist with exact fallbacks; pattern, texture, and procedural fills edit in place and live in a searchable fill library.
- Strokes carry alignment, three dash pairs with dash adjustment, arrowheads, behind-fill, scale-with-object, calligraphic nibs, and variable width profiles.
- Objects, groups, and layers carry stacked appearances; one style system covers graphic and object styles and default object properties.
- Art, pattern, scatter, calligraphic, image, bristle, and painterly brushes keep their paths editable; the Paintbrush and Blob Brush draw with stylus pressure.
- Opacity, 16 standard blend modes plus Corel merge modes, opacity masks, fountain and pattern transparency, knockout, and feather render and persist.
- Symbols support overrides, 9-slice scaling, registration points, nesting, clones, and linked libraries, and the symbol sprayer and seven symbolism tools sculpt symbol sets.
