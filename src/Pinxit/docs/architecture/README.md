# Architecture

Technical architecture documentation for Pinxit.

## Overview

Pinxit is built with a layered architecture:

1. **UI Layer** - WPF + WPF-UI
2. **Application Layer** - Services and ViewModels
3. **Domain Layer** - Core business logic
4. **Infrastructure Layer** - Rendering, File I/O

## Key Systems

- Tiled Rendering System
- Render Graph Pipeline
- Non-Destructive Editing
- Plugin Architecture
