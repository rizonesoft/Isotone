## Developer Documentation

This folder contains developer‑facing documentation for the Photon monorepo:

- `architecture.md` — High‑level architecture of Photon, Bezier, Imago, and shared libraries.
- `build-and-run.md` — How to build, run, and debug each app (Bezier, Imago) from the monorepo.
- `debug-tools.md` — Overview of built‑in debug/dev tools (e.g., Bezier debug window, Imago diagnostics).
- `contributing.md` — How to work with `TODO.md`, prompts, and the `standards/` folder.

All feature work and polish tasks should keep these docs up‑to‑date as part of the completion criteria.
