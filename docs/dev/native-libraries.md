# Native libraries

The dependency register: every library the native suite installs through vcpkg, with its version, provenance, license, advisory identity, and owner (`standards/cpp.md`, Libraries; the spec's "Dependencies and their upkeep"). `python scripts/native-deps-lint.py` keeps this table and the installed ports in step, in `scripts/check-all.ps1` (`native deps`) and CI, and `scripts/check-native-advisories.py` (`D00 T04 §3`) checks every row's advisory identity daily.

**Adding a library.** The section that first uses a library adds its row in the same commit, and a row for every port it pulls in, transitive ones included, then runs the lint. A row leaves only with the last code that uses it.

**The columns.** Version is the port version the baseline resolves (`<version>` or `<version>#<port-version>`). Upstream repository is the URL of the release's Git repository and Released tag the tag the port builds, both as the port's `vcpkg.spdx.json` records them; Advisory identity is `osv-git:<repository>@<tag>` for a library OSV tracks by Git, or `feed:<url>` for one with its own advisory feed. Linked by names the apps that link it, or `tests`, `bench` (developer-only), or `build-time` (a vcpkg helper port, installed for the build machine only). Pulled in by is `direct` (in `native/vcpkg.json`) or the registered port that depends on it. CRT is `static` (built against `LIBCMT`), or `none: <reason>` for a library with no CRT directive (assembly only, or `/Zl`), the only way `scripts/native-artifact-gate.py` accepts one. Runtime module is `none`, or the DLL name the suite loads at run time from it (`standards/cpp.md`, Calling Windows).

**Helper ports.** A vcpkg registry helper (`vcpkg-cmake`, `vcpkg-cmake-config`) holds the registry's CMake scripts rather than an upstream release and is installed for the build machine's triplet only, never linked: its row names the repository `https://github.com/microsoft/vcpkg`, the Released tag of the committed `builtin-baseline`, and the Advisory identity `none: build-time helper, not linked`, and the lint checks exactly those values.

**The C# apps' native payloads are not registered.** The 2026-09-30 version of this register inventoried the native files the C# apps shipped (SkiaSharp's native assets and the like). No C# app ships again: each C# tree is a behavior reference, retired at its native app's first release (the spec's "The repository during the move"), so that inventory is superseded (`todo/supersession-2026-10.md`, `D00 T04 §1`). Its acceptance requirements carry forward through this register: the Notices shipped column is the notice each native app must carry, and the Architectures column the per-architecture requirement.
