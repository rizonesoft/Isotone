## User Documentation

This folder contains user‑facing documentation for the Photon apps:

- `bezier-getting-started.md` — How to install and start using Bezier from this monorepo.
- `imago-getting-started.md` — How to install and start using Imago.
- `troubleshooting.md` — Common issues, where to find logs, how to report problems.

When a user‑visible feature is added or polished, update or create the relevant guide here as part of the task.
