# Editing the design system

`docs/design/` is the only home of the Photon Interface design system (operator decisions, 2026-09-27: full import into the repository, then the Claude artifact copies were deleted). There is no other copy to keep in step.

The public view is `docs/design/index.html`, generated by `scripts/build-design-site.py` and deployed to https://rizonesoft.github.io/Photon/design/ by `.github/workflows/pages.yml` on every push to `main` that touches `docs/design/**`, `resources/icons/**`, or the build script.

## Making a change

1. Edit the sources: `tokens.json` for any value (colors per theme, type, spacing, radius, shadow, size, duration), `README.md` and the section files for guidance, `components/<Comp>/README.md` and `preview.html` for a component, `components/bundle.css` and `bundle.js` for shared preview styles and the icon catalog.
2. Regenerate the page: `python scripts/build-design-site.py`.
3. Run the gates: `python scripts/build-design-site.py --check` (the committed page matches its sources) and, once `D01 T01 §3` ships, the theme generator's drift check (the `Photon.UI` XAML matches `tokens.json`).
4. Commit the sources and the regenerated `index.html` together. The Pages workflow deploys after the push.

Never hand-edit `index.html` or the generated `Photon.UI` theme dictionaries: they are rebuilt from the sources and the drift checks fail on hand edits.

## App icons

The app icon SVGs live in `resources/icons/<app>/` and are documented in `resources/icons/README.md` and `app-icons.md`. The page embeds them directly. `design-system.json` keeps the "App icons" asset records from the import only so the `AppIcon` preview's `/_blob/<id>` references resolve to those files when the page is built; a new icon needs a record there with its file name.

## Checks

- `docs/design/tokens.json` and `docs/design/design-system.json` must parse as JSON.
- Every color token has a value for all four themes and a usage note; text pairs meet the contrast targets in `standards/ui.md` in every theme.
