## Self-review

1. Does it make sense? One command now runs every native gate: `check-all` builds and tests every preset, analyzes both architectures, checks the standard switch, the PE hardening, format, tidy, imports by policy, and sanitizer coverage, and runs the gates' own tests; a failing native test fails its stage while every later stage still runs. The filed items harden the gates those stages call, each proved by a probe run the way its stage runs it and by a mutant of its test.
2. Is it logical? Each stage enters the pinned environment only where it builds or inspects, keeps its full log under `build/check-all/`, and prints its tail on failure; the import gate splits by policy and requires every preset built, so a partial artifact set cannot pass; the sanitizer probe's verdict depends on its own report, never on an exit code.
3. Did it break anything else? The .NET build and tests and every Python gate still pass; the C# apps' publish folders under `artifacts/publish/<App>/` are outside the native size gate by construction (`publish_root`).

### F6 -- a sanitizer abort dialog held CTest for ten minutes -- reproducibility -- fixed (self) [minor]

Found by the first run of `test_native_asan.py`: with CMake's default DLL CRT the sanitizer's abort raised a message box. Fixed in `e577362`: the scratch project runs the real lane's configuration, and every test preset fails a test after 300 seconds.

### F7 -- two defects in the first check-all native stages -- correctness -- fixed (self) [minor]

Found by the first full run: `native analyze` ran both architectures in one process, so the first block's `Push-Location native` carried into the second (`native\native`), and reading `hidden` on presets that lack it threw under `Set-StrictMode`, aborting check-all before its table. Fixed in `e577362` before the ship commit.

### F8 -- native-tidy missed a command-line error with no file prefix -- correctness -- fixed (self) [minor]

Found while testing `--removed-arg`: `error: argument unused during compilation` has no `file:` prefix, which the diagnostic pattern required. Fixed in `e577362`: a line starting `error:` or `warning:` counts.

### F9 -- the PE check skipped every image under CMakeFiles -- consistency -- fixed (self) [minor]

Found in self-review: `native-pe-check.py` still left out all of `CMakeFiles`, while the artifact gate (D00 T05 §6) skips only CMake's compiler-identification probe. Fixed in `e577362` with the same rule and a self-test case.
