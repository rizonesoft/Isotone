2. **P1** `native/core/src/atomic_file.cpp:480`: Retrying a write after failed rollback can destroy the last good backup. `Session::write` never settles an existing backup before using that same path for the next replacement. Reproduce a target readback failure followed by a restore failure, possible with an intermittently unavailable portable drive. Once accessible again, retry the write without an intervening read, and fail its target readback too. The second replacement backs up the unverified target over the original good backup; rollback now restores that unverified version. The contract expressly requires the next **read or write** to preserve and settle the last good copy. The replacement API uses the supplied backup path for the replaced target.
