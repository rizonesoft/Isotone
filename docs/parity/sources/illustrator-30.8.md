# Adobe Illustrator feature inventory (parity reference for Stilus)

> **Provenance note (2026-09-26):** verbatim copy of the Adobe Illustrator 30.8 inventory compiled for the Stilus parity plan. The AI-#### ids are stable and each is placed in exactly one row of [`../stilus-parity.md`](../stilus-parity.md). Do not renumber; a future Illustrator version appends new ids after AI-1294 (see [`../README.md`](../README.md)).

- **Product:** Adobe Illustrator 2026 on desktop
- **Latest version:** 30.8 (August 2026 release; release notes page last updated Aug 31, 2026). Current LTS: 29.8.7 (May 2026).
- **Major version baseline:** Illustrator 2026 = 30.0, released October 2025 (community announcement dated Oct 28, 2025).
- **Inventory date:** 2026-09-26
- **Scope:** Tools (including hidden flyout tools), menus, panels, effects, live features, type, color, formats, print and prepress, preferences, workspace, automation, cloud and AI features. Features that are cloud services, scripting/automation or generative AI are tagged in the Category column (`cloud`, `automation`, `ai`) so they can be excluded from a GPL desktop parity plan. `format` = file I/O, `print` = print and prepress, `core` = everything else.
- **Kind values:** tool, command, panel, panel-option, effect, dialog, format, preference, behavior.
- **Method:** helpx.adobe.com blocks non-browser fetches (HTTP 403), so pages were read through a real browser session. Rows are grounded in the pages below; where a help page only names a feature, the one-line description reflects Illustrator's documented behavior. Rows marked "(removed)" are legacy formats kept for completeness. Version tags like (30.0) mark when a feature arrived.
