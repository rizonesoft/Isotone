## Lessons

- A parser that guards a count is reviewed adversarially until it runs out of shapes: recognise rows by structure and state a strict format rule for the files rather than emulating a renderer, or each round finds one more shape (D00 T01 §6 took eleven).
- Quote round clocks from the dispatcher summary (`run`), never from the shell after the call returns: they differ by a second and the stamp review names them.
- A probe or round that writes a manifest keeps it beside its own review in a folder of its own: two rounds sharing one manifest path leave a kept review that no longer replays against its checker (D00 T01 §4 F1).
- Run `python scripts/todo-graph.py plan --sync` before committing any TODO or backlog filing: the hook runs `validate` only, so a filing commit can leave the plan's Progress line stale for CI's `plan --check`.
- First stamp in the repository: a ledger `duplicate` row must name a canonical finding id, so a finding already owned by a planned section is `rejected already owned: <ref>`; `todo-runs.py` reads panel verdict lines that open with the backtick (no list marker); the attestation's `--reviewer` is the derived rung `codex-panel`; SOURCE keys must be unique per target section.
- Delegate the gate sweep before the last prose edits only if those edits are re-gated: the D00 T01 §2 verifier run caught the stale claim this section's change created, and the fix after it was re-gated by the lead (validate, plan --check, claims, self-test).
- Keep the panel helper's exec line in the bounded output (round 3's latency had to be recovered from file times).
