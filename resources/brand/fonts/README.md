# Brand fonts

| File | Font | License | Used for |
| ---- | ---- | ------- | -------- |
| `Sora-wght.ttf` | Sora, variable weight 100 to 800, from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/sora) (upstream: [sora-xor/sora-font](https://github.com/sora-xor/sora-font)) | SIL Open Font License 1.1, [`Sora-OFL.txt`](Sora-OFL.txt) | The Isotone wordmark: "isotone" in SemiBold (600), "GRAPHICS SUITE" in Medium (500) |

Install `Sora-wght.ttf` to use Sora in design tools; it holds every weight. The wordmark files under `resources/brand/` are outlines generated from it by `scripts/build-suite-mark.py`, so they render without the font installed. The apps' interface font is Segoe UI Variable, which ships with Windows and is not redistributed here.
